-Student Management System
A simple DBMS project designed to manage student records, courses, subjects, and enrollments using a structured database approach.
-Overview
This system replaces manual record-keeping with a database-driven solution. It stores student information, course details, and subject assignments, and allows administrators to enroll students into the appropriate courses and subjects. The project demonstrates core DBMS concepts such as relational modelling, normalization, and SQL-based data operations.
-features
Add, update, and delete student records
Manage courses and subjects
Enroll students into courses and subjects
Retrieve and view student and course information
Basic reporting and database queries
-Technologies Used
Database: MySQl
Interface or Backend: Python / PHP
SQL scripts for database schema and sample data
